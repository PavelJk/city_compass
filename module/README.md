# Модуль «Инвестиционная привлекательность жилья»

Модуль для «Цифрового двойника инфраструктуры» (проект `mptt2`). Тема: геоинформационная система оценки
инвестиционной привлекательности жилой недвижимости на основе цен продажи и аренды (Йошкар-Ола, Медведево, Семёновка, Руэм).

Один файл: **`realty_module.py`**. Проект преподавателя не изменялся.

## Установка

1. Положить `realty_module.py` в папку `modules/` проекта (или загрузить через «Модули → Управление модулями → Загрузить .py»).
2. В «Управление модулями» нажать «Активировать» у `realty_module`, перезапустить приложение.
3. В меню «Модули» появится пункт **«Инвестиционная привлекательность жилья»**.
4. Первый запуск создаёт свои таблицы и загружает встроенные данные (180 объявлений и 9 668 мест из OpenStreetMap). Нажать
   «Данные → Пересчитать» (около 3 секунд).

Дополнительных библиотек не нужно: только то, что уже есть в проекте (Flask) и стандартная библиотека Python 3.8+.
Проверено на Python 3.11, Flask 3.1, проект из архива без правок.

## Что берётся из проекта

| Таблица проекта | Как используется |
|---|---|
| `nodes`, `edges` | дорожный граф (61 533 узла, 129 765 рёбер): кратчайшие пути от квартиры до мест (алгоритм Дейкстры, до 2,2 км) |
| `nodes` (типы «Остановка», «Пешеходный переход», «Светофор») | остановки как места; число переходов и светофоров в 300 м от квартиры |
| `buildings` | к зданию проекта привязывается каждое объявление (по попаданию в прямоугольник здания, иначе ближайшее в 60 м); карта окрашивает здания |
| `characteristics`, `data` | **запись результатов** (см. ниже) |
| `settings` | настройки модуля, ключ `realty_settings` |

## Что записывает в общие таблицы

Для каждого здания, к которому привязаны квартиры (по лучшей квартире в здании), модуль создаёт характеристики
(`applies_to = 'building'`) и записывает значения (`weekday = 0`, `hour = 0`, значение статично):

- «Индекс среды (0–100)»
- «Цена, ₽/м²»
- «Чистая доходность, %»
- «Индекс выгодности (0–100)»

Их видно в окне характеристик здания на главной карте и можно использовать в других модулях.
При каждом пересчёте старые значения этих четырёх характеристик заменяются новыми.

## Собственные таблицы

`realty_flat` (объявления), `realty_poi` (места: магазины, школы, остановки, парки и минусы — промзоны, магистрали, бары),
`realty_result` (результаты расчёта по квартирам). Все имена начинаются с `realty_`, конфликтов с другими модулями нет.

## Как считается

1. **Пешая доступность.** От ближайшего узла графа до каждого места строится кратчайший путь по рёбрам проекта. Для мест
   с радиусом влияния до 2,2 км берётся длина пути, для остальных (шум, запахи, дальние места) — расстояние по прямой.
2. **Индекс среды 0–100.** 7 групп положительных мест (транспорт 20, школы и сады 15, медицина 10, магазины 10, зелень 15,
   спорт и культура 10, сервисы 10) с затуханием по расстоянию; у школ, больниц и т. п. есть «оптимальная» дистанция
   (слишком близко — хуже). Минусы (промзона, железная дорога, магистраль, бары, АЗС, ЛЭП…) вычитаются.
   `индекс = 40 + 0,65 × плюсы − min(55; 2,5 × минусы)`, в пределах 5–95.
3. **Аренда.** Реальных арендных объявлений в данных нет, поэтому аренда — оценка: типичная аренда по комнатности × размер,
   уровень цен соседних квартир в 1,5 км и поправки (среда ±12%, населённый пункт, новостройка/вторичка, крайний этаж). Если в объявлении указана аренда — берётся она. Результат всегда в диапазоне 20–35 тыс. ₽ (настраивается).
4а. **Перепродажа.** Цена через N лет = цена × (1 + сближение с ценой соседей) × (1 + рост)^N (рост: база 5% + среда ±1,5 + новостройка +1 + пункт), минус расходы на продажу и налог (13% с прибыли при владении < 5 лет). Считаются прибыль, рост в год и общая доходность аренды и продажи (IRR). Параметр «Цель» (сдавать / перепродать / оба) в настройках определяет, по какой доходности строится индекс выгодности.
4. **Доходность.** Чистый доход = аренда × (12 − простой) − управление − ремонт − налог − налог на имущество;
   чистая доходность = доход ÷ (цена + подготовка к сдаче + расходы на сделку); окупаемость = вложения ÷ доход.
5. **Индекс выгодности 0–100** = 70% доходность (2% → 0, 6% → максимум) + 15% индекс среды + 15% цена за м² относительно
   медианы соседей в радиусе 1,5 км (того же рынка). Веса и ставки настраиваются на вкладке «Настройки».

## Интерфейс

- Карта (Leaflet): здания проекта с объявлениями окрашены по индексу выгодности, на мелком масштабе — точками.
- Рейтинг квартир и карточка «Паспорт объекта» в стиле проекта (таблицы): параметры, доходность, из чего складывается оценка
  (баллы по трём частям), ближайшие места с расстоянием и временем пешком, минусы рядом, остановки/переходы/светофоры, выводы.
- Настройки (ставки аренды, налоги, веса) → «Сохранить и пересчитать».
- Данные: счётчики, пересчёт, загрузка встроенных данных, импорт своих объявлений (JSON).

## API модуля

`GET /modules/realty/api/flats`, `.../buildings`, `.../summary`, `.../status`, `GET|POST .../settings`, `POST .../recalc`,
`POST .../reseed`, `POST .../import` (multipart, файл JSON со списком объявлений).

## Ограничения

- Граф проекта построен по дорогам для автомобилей (`drive`), тротуары и дворовые тропы в нём отсутствуют; пешие расстояния
  по нему — приближение. Для точности нужен граф с `walk`.
- Индекс среды — эвристическая модель, а не научный показатель; модель не гарантирует прибыль.
- Расчёт ведётся для зданий, где есть объявления, а не для всех 43 тысяч зданий проекта.
- Фото объявлений в модуль не включены (только ссылка на объявление).

## Как обновить встроенные данные

В исходниках основного проекта: `python module/build_module.py` пересобирает `realty_module.py` из `dist/data/listings.json`
и `dist/data/poi.json`.
