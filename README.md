# Городской компас

Веб-приложение для выбора квартиры, которую выгоднее сдавать: Йошкар-Ола, Медведево, Семёновка, Руэм.
Карта с сеткой шестиугольников (индекс среды по ~10 тыс. мест из OpenStreetMap), рейтинг квартир по доходности аренды,
сравнение, настраиваемая модель, профиль с входом.

Подробная документация простым языком — в папке [docs](docs/README.md): как пользоваться, как всё считается, откуда данные, как обновить и опубликовать.

## Запуск

```
python server/app.py            # http://127.0.0.1:4183
```

Нужен Python 3.10+. Сервер отдаёт `dist/` (со сжатием и кешем) и API входа/профиля (SQLite `data/users.db`).
Без сервера `dist/` работает как статический сайт: вход недоступен, настройки хранятся в браузере.

## Данные

| Что | Откуда | Как обновить |
|---|---|---|
| Объявления | страницы Авито, сохранённые в браузере → `data/inbox/` | `python scripts/sync_listings.py` (ежедневно в 07:00 через Планировщик Windows) |
| Веб-архивы Safari (Telegram) | `.webarchive` | `python scripts/import_webarchive.py <файл> <имя>` → `data/inbox/` |
| Новостройки | файл с именем `avito-new*.html` заменяет все остальные новостройки в базе | то же |
| Места (магазины, школы, транспорт, негатив…) | `data/osm/mari_el.pbf` (выгрузка OpenStreetMap) | `python scripts/build_poi_from_pbf.py` (нужен `pip install osmium`) |
| Пешеходный граф улиц | тот же `data/osm/mari_el.pbf` | `python scripts/build_walk_graph.py` → `dist/data/walk.bin` (нужен `pip install osmium`) |
| Фото | скачиваются из страниц, к ним делаются миниатюры (`pip install pillow`) | входит в `sync_listings.py`, лишние файлы удаляются сами |

Результат: `dist/data/listings.json`, `dist/data/poi.json`, `dist/assets/photos/`.

## Модель

- **Цель — сдавать, продать или оба** (переключатель в панели карты). Для перепродажи считается цена через N лет: цена × (1 + сближение с ценой соседей) × (1 + рост)^N, рост = базовый + среда + новостройка + населённый пункт; затем расходы на продажу и налог (13% с прибыли, если владели меньше 5 лет). Показываются прибыль с продажи, рост в год и общая доходность аренды и продажи вместе (IRR). Индекс выгодности, цвет карты, сортировка и рейтинг следуют выбранной цели; параметры — в разделе «Модель».
- Аренда = типичная аренда по комнатности (20–35 тыс. ₽, ориентир — средние по объявлениям) × размер, цены соседних квартир и поправки (среда, населённый пункт, новостройка/вторичка, крайний этаж). Реальных арендных
  объявлений в базе нет — это оценка; точную сумму можно ввести в карточке квартиры.
- Чистый доход = аренда × (12 − простой) − управление − ремонт − налоги; доходность = доход ÷ (цена + подготовка + сделка).
- Оценка 0–100: доходность, среда, цена против соседей в радиусе 1,5 км (веса и шкала настраиваются в окне «Модель»).
- Индекс среды: группы мест с весами, у каждой категории свой радиус и «оптимальная» дистанция; минусы затухают с расстоянием.
  Расстояния до «плюсов» (магазины, школы, остановки…) считаются пешком по улицам (граф `walk.bin`, расчёт в фоновом потоке,
  радиус до 2,2 км), до шумных и вредных объектов — по прямой; в окне «Модель» можно вернуть расчёт по прямой.
  Индекс — эвристика, а не научный показатель.

## Ограничения

- Парсер читает только то, что сохранено в страницах; у части объявлений нет фото (показывается значок дома с пометкой).
- Для публикации в интернет сервер ставят за HTTPS и включают `COMPASS_SECURE_COOKIE=1`.
