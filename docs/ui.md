
## Шапка и профиль
- Шапка — одна стеклянная полоса: кнопка меню карты, вкладки, тема/профиль.
- Сортировка списка — кнопка в шапке панели квартир (меню с галочкой), выбор запоминается (`LS sort`).
- Аватар по умолчанию — силуэт, без букв.
- Профиль: две колонки (аккаунт, интерфейс | избранное, безопасность). «Интерфейс»: тема, подложка, стартовая вкладка, сортировка, пустые ячейки, только с фото, анимации. «Мои данные»: экспорт/импорт JSON и сброс. Те же блоки есть без входа (Vercel).

## Правки шапки (v180)
- Шапка снова из трёх отдельных блоков одной высоты (`--bh`), на мобильных всё центрируется в одну строку.
- Тема и справка перенесены в меню карты («Оформление»).
- Кнопка «»» в шапке панели квартир скрывает панель (чистая карта); возвращает плавающая кнопка «Квартиры» или выбор объекта.
- В карточке убраны полосы у сценариев аренды/продажи; вкладка «Вместе»; график и шапка профиля не выходят за экран; «Выйти» — иконка.
