# 06. Запуск и публикация в интернете

## Вариант 1. Запустить на своём компьютере

Нужен **Python 3.10 или новее**. Больше ничего ставить не надо.

1. Откройте папку проекта в терминале.
2. Выполните:

```
python server/app.py
```

3. Откройте в браузере адрес **http://127.0.0.1:4183**.

Сайт работает, пока терминал открыт. В этом режиме работает **вход и профиль**: пользователи хранятся в файле `data/users.db`.

Если нужен другой порт: `python server/app.py --port 5000`.

## Вариант 2. Опубликовать сайт в интернете (Vercel)

Так сайт открывается у любого человека по ссылке, а ваш компьютер может быть выключен.
Подходит бесплатный тариф Vercel. Сайт публикуется как набор готовых файлов, поэтому **вход и профиль на нём не работают** — избранное, сравнение и настройки сохраняются в браузере посетителя.

### Один раз

1. Зарегистрируйтесь на **github.com** и **vercel.com** (на Vercel проще всего войти через GitHub).
2. На GitHub нажмите «New repository», назовите, например, `gorodskoy-kompas`, **ничего не добавляйте** (ни README, ни .gitignore) и создайте.
3. В папке проекта выполните (подставьте свой логин):

```
git remote add origin https://github.com/ЛОГИН/gorodskoy-kompas.git
git push -u origin main
```

   Git откроет окно входа в GitHub.
4. На **vercel.com/new** выберите этот репозиторий и нажмите **Deploy**. Настройки менять не нужно — они уже записаны в файле `vercel.json` (публикуется папка `dist`, сборка не нужна).
5. Через минуту появится адрес вида `название.vercel.app`.

### Как обновить сайт

Любые изменения (новые квартиры, правки текста) — тремя командами:

```
git add -A
git commit -m "обновил данные"
git push
```

Vercel сам заметит и за минуту опубликует новую версию.

### Что не попадает в интернет

Файл `.gitignore` не пускает на GitHub: базу пользователей (`data/users.db`), ваши сохранённые страницы (`data/inbox/`) и большой файл карты (`data/osm/`).

### Приватность

- Репозиторий на GitHub можно сделать закрытым: Settings → Danger Zone → Change visibility → Make private. Vercel продолжит работать.
- Сам сайт всегда открыт для всех, у кого есть ссылка. Имени владельца на сайте нет.
- Не оставляйте в файлах личную почту и пароли.

## Вариант 3. Свой сервер с входом и профилем

Если нужен вход в публичной версии, запустите `server/app.py` на сервере, который не выключается (VPS, Render, Railway и подобные), поставьте перед ним защищённое соединение (HTTPS) и включите защищённые cookie:

```
COMPASS_SECURE_COOKIE=1 python server/app.py
```

Эта настройка нужна, только когда сайт работает по HTTPS.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| «python не найден» | Установите Python с python.org и поставьте галочку «Add to PATH» |
| Страница пустая, карта серая | Нет интернета: карта и значки грузятся из сети |
| На сайте старая версия | Обновите страницу с очисткой кеша (`Ctrl+F5`); если правили файлы — поменяйте число после `?v=` в `dist/index.html` |
| Порт занят | Запустите на другом порту: `python server/app.py --port 5000` |
| Квартиры не видны | Проверьте, что файл `dist/data/listings.json` есть и не пустой |
