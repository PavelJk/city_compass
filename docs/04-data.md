# 04. Данные: откуда берутся и как обновлять

Сайт ничего не ищет в интернете сам. Он показывает **готовые файлы**, которые лежат в папке `dist/data/`.
Эти файлы собираются маленькими программами из папки `scripts/`. Ниже — какие файлы есть, откуда они и как их обновить.

## Какие данные есть

| Файл | Что внутри | Откуда |
|---|---|---|
| `dist/data/listings.json` | квартиры на продажу: адрес, цена, площадь, комнаты, координаты, фото, ссылка | сохранённые страницы сайтов объявлений |
| `dist/data/poi.json` | около 9 700 «мест»: магазины, школы, остановки, парки, а также минусы — промзоны, железная дорога и т. п. | OpenStreetMap |
| `dist/data/walk.bin` | улицы города для расчёта пеших маршрутов | OpenStreetMap |
| `dist/data/buildings.json` | контуры домов, в которых продаются квартиры | OpenStreetMap + объявления |
| `dist/assets/photos/` | фото квартир и их уменьшенные копии (`t/`) | скачиваются из сохранённых страниц |

**OpenStreetMap (OSM)** — свободная карта мира, которую рисуют и дополняют люди. Исходный файл для нашего региона называется `data/osm/mari_el.pbf` (он большой и в интернет не выкладывается).

## Как обновить объявления

1. **Сохраните страницы.** Откройте выдачу Авито (или Этажей) в обычном браузере и сохраните страницу целиком: `Ctrl+S`, тип файла «Веб-страница полностью». Так сохранятся и фото.
   Прокрутите выдачу до конца и сохраните каждую страницу выдачи отдельно.
2. **Положите файлы в `data/inbox/`:** сам `.html` и одноимённую папку `…_files`.
   - Файл новостроек называйте так, чтобы имя начиналось с `avito-new` (например, `avito-new1.html`). Такие файлы **заменяют все** новостройки в базе, остальные — добавляются.
   - Вместо страниц можно положить таблицу CSV или файл JSON по образцу `data/inbox-template.csv`.
   - Страницы из Safari (файлы `.webarchive`, например присланные в Telegram) сначала преобразуйте: `python scripts/import_webarchive.py <файл> <имя>` — результат ляжет в `data/inbox/`.
3. **Запустите обновление:**

```
python scripts/sync_listings.py
python scripts/build_buildings.py
```

Что делают эти команды:
- `sync_listings.py` читает всё из `data/inbox/`, находит адрес, цену, площадь, фото, определяет координаты (по адресу, через открытый сервис Nominatim), убирает повторы, оставляет только наши четыре населённых пункта, скачивает фото и делает уменьшенные копии, удаляет ненужные фото. Результат — `listings.json`.
- `build_buildings.py` для каждого адреса ищет **настоящий дом** в данных OpenStreetMap и ставит квартиру точно в него (это исправляет ошибки геокодера). Результат — `buildings.json`, а координаты в `listings.json` уточняются.

4. **Если сайт опубликован** — отправьте изменения (см. [06](06-launch-and-publish.md)).

### Объявления с Яндекс Недвижимости

Выдачу Яндекс Недвижимости (около 1 500 объявлений по нашим пунктам) собирают в обычном браузере по страницам: сайт отдаёт данные без капчи, но запросы нужно делать неспешно (раз в 1–2 секунды). Собранные строки кладутся в `data/inbox/ya_chunk*.txt` (формат описан в начале `scripts/yandex_to_inbox.py`), затем:

```
python scripts/yandex_to_inbox.py      # превращает выгрузку в data/inbox/yandex.json
python scripts/sync_listings.py        # объединяет с Авито, убирает дубли, определяет координаты
python scripts/build_buildings.py
```

Повторяющиеся квартиры в одном ЖК (одинаковые площадь, комнаты и цена на разных этажах) сворачиваются в одну. Фото Яндекса не скачиваются, а показываются по ссылке. Одно и то же объявление на Авито и Яндексе остаётся один раз (совпадают адрес, площадь и цена в пределах 3%).

### Автоматическое обновление каждый день

На компьютере с Windows создано задание **InvestKarta-SyncListings**: каждый день в 07:00 оно запускает `scripts/run_sync.cmd`, а тот выполняет обе команды выше и пишет запись в `data/sync.log`.
Само задание только обрабатывает то, что лежит в `data/inbox/`: **новые страницы в эту папку нужно класть самим**. Компьютер должен быть включён (или задание выполнится при следующем запуске).

## Как обновить места и улицы

Нужно редко (когда в OSM появилось много нового). Положите свежий файл региона в `data/osm/mari_el.pbf` и выполните:

```
python scripts/build_poi_from_pbf.py     # места -> poi.json
python scripts/build_walk_graph.py       # улицы -> walk.bin
```

Для этих команд нужно один раз поставить библиотеки: `pip install osmium shapely pillow`.

### Как отсеиваются закрытые места

В OpenStreetMap остаётся много мест, которые давно закрылись. При сборке `poi.json` программа:
- выбрасывает объекты, помеченные как закрытые или заброшенные;
- для магазинов, кафе, аптек, банков, офисов, баров и других «быстро закрывающихся» мест оставляет только те, которые правили на карте **не раньше 2021 года** (или у которых есть отметка проверки не раньше 2023). Школы, детские сады, больницы, остановки, парки, дороги и т. п. остаются всегда.

Границы годов лежат в начале `scripts/poi_rules.py` (`FRESH_FROM`, `CHECKED_FROM`), их можно поменять и пересобрать места.

## Как программа понимает адрес

- Из текста вроде «Йошкар-Ола, ул. Строителей, 3» берутся улица и номер дома.
- Если в OSM есть дом с таким адресом — квартира попадает точно в него.
- Если номера нет («жилой дом» без номера) — точка условная: такая квартира помечается как «приблизительная», а её дом рисуется пунктирным прямоугольником.
- Если OSM предлагает точку слишком далеко (больше 3 км) от найденной геокодером, программа **не доверяет** ей и оставляет прежнюю, чтобы не ошибиться улицей-тёзкой в другом посёлке.

## Чего в данных нет

- **Настоящих объявлений об аренде.** Аренда оценивается формулой (см. [03](03-how-it-works.md)).
- **Автоматической загрузки с Авито/Этажей.** Эти сайты закрывают доступ программам, поэтому страницы сохраняются руками. Мы не обходим защиту сайтов.
- **Этажей и года дома** у части объявлений — они берутся из заголовка, если там указаны.

## Для проверки

Раздел «Данные» на сайте (значок «?») показывает, сколько объявлений и мест в базе, когда они обновлены и какие пункты и источники представлены.
