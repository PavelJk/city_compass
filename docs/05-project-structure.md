# 05. Из чего состоит проект

Проект — это обычные файлы в одной папке. Сборки и сложных программ для запуска сайта не нужно.

## Папки

```
invest-karta/
├── dist/            сам сайт (то, что видит посетитель)
│   ├── index.html   единственная страница
│   ├── css/app.css  весь внешний вид
│   ├── js/          вся логика сайта (по файлам, см. ниже)
│   ├── data/        готовые данные: квартиры, места, улицы, дома
│   └── assets/photos/  фото квартир (и t/ — уменьшенные копии)
├── server/app.py    небольшой сервер: отдаёт сайт и хранит профили
├── scripts/         программы, которые собирают данные
├── data/            рабочие файлы: сохранённые страницы, кеш адресов, база пользователей, карта OSM
├── module/          модуль для проекта преподавателя
├── docs/            эта документация
├── vercel.json      настройки публикации на Vercel
└── README.md        краткая справка
```

## Файлы сайта (`dist/js/`)

Каждый файл отвечает за свою часть:

| Файл | За что отвечает |
|---|---|
| `app.js` | запуск: загрузка данных, шапка, вкладки, окна |
| `state.js` | общие настройки и «память» (что выбрано, фильтры, избранное) |
| `config.js` | все числа по умолчанию: типичная аренда, налоги, веса, рост цен, список из 69 видов мест |
| `model.js` | загрузка данных и расчёт для каждой квартиры, фильтры, сортировка |
| `finance.js` | формулы: аренда, доходность, окупаемость, перепродажа, итоговая оценка |
| `score.js` | индекс среды (что и на каком расстоянии) |
| `hex.js` | построение сетки шестиугольников |
| `map.js` | карта: цвета ячеек, подписи, волна при наведении, дома, места, легенда, приближение |
| `flat.js` | правая панель: список, фильтры, карточка квартиры, объяснение оценки |
| `pages.js` | страницы «Рейтинг», «Сравнение», «Модель», «Данные», «Профиль» |
| `own.js` | свои квартиры: форма добавления, выбор точки и рисование участка на карте |
| `walk.js`, `walk-worker.js` | пешие маршруты по улицам (считаются в фоне, чтобы сайт не тормозил) |
| `dropdown.js` | красивые выпадающие списки |
| `api.js` | вход, профиль, сохранение настроек на сервере |

Подключённые со стороны: карта Leaflet, значки Font Awesome, шрифт Inter. Они грузятся из интернета.

## Программы для данных (`scripts/`)

| Файл | Что делает |
|---|---|
| `sync_listings.py` | читает сохранённые страницы, собирает `listings.json`, скачивает фото |
| `build_buildings.py` | находит дома и уточняет координаты, делает `buildings.json` |
| `build_poi_from_pbf.py`, `poi_rules.py` | собирают места из OSM в `poi.json` (правила, что считать магазином, школой и т. д.) |
| `build_walk_graph.py` | делает файл улиц `walk.bin` |
| `import_webarchive.py` | переводит файлы Safari `.webarchive` в обычные страницы |
| `run_sync.cmd` | запускает ежедневное обновление на Windows |
| `sources.json` | список внешних источников (сейчас пустой) |

## Сервер (`server/app.py`)

Маленькая программа на Python без лишних библиотек. Она:
- отдаёт сайт (сжимает файлы и помнит их, чтобы открывалось быстро);
- хранит пользователей в файле `data/users.db` (пароли не хранятся — хранится их защищённый «отпечаток»);
- сохраняет настройки, избранное, сравнение и свою аренду в аккаунте.

Без сервера сайт тоже работает — просто без входа.

## Как данные попадают на экран

1. Посетитель открывает `index.html`.
2. Сайт загружает четыре файла из `dist/data/` (квартиры, места, дома, улицы).
3. `model.js` для каждой квартиры считает аренду, доходность, продажу, среду и итоговую оценку.
4. `map.js` красит ячейки, `flat.js` рисует список.
5. Любое изменение настроек («Модель», цель, фильтры) запускает пересчёт и перерисовку.

## Где что менять

| Хочу изменить | Где |
|---|---|
| типичную аренду, налоги, рост цен, веса | `dist/js/config.js` (или страница «Модель» на сайте) |
| формулу оценки | `dist/js/finance.js` |
| что считать «плюсом» или «минусом» рядом | `dist/js/config.js` (список мест) и `scripts/poi_rules.py` |
| внешний вид | `dist/css/app.css` |
| тексты страниц | `dist/js/pages.js` и `dist/js/flat.js` |

После правок в файлах сайта поменяйте число после `?v=` в `dist/index.html` (например, `app.js?v=123` → `?v=124`): так браузеры посетителей загрузят новую версию, а не старую из памяти.
