# 07. Модуль для проекта преподавателя

## Что это

Проект преподавателя («цифровой двойник» города) состоит из модулей: каждый студент пишет свой модуль, а преподаватель собирает их в один проект.
Наш модуль добавляет в проект раздел **«Инвестиционная привлекательность жилья»**: те же квартиры, те же расчёты, но внутри проекта преподавателя и на его карте и данных.

Весь модуль — **один файл `realty_module.py`** (в папке `module/`). Сам проект преподавателя мы не меняли.

## Как поставить

1. Положите `realty_module.py` в папку `modules/` проекта преподавателя (или загрузите через «Модули → Управление модулями → Загрузить .py»).
2. В «Управление модулями» нажмите **«Активировать»** у `realty_module` и перезапустите приложение.
3. В меню «Модули» появится пункт «Инвестиционная привлекательность жилья».
4. При первом запуске модуль сам создаст свои таблицы и загрузит встроенные данные (180 объявлений и около 9 700 мест). Нажмите на вкладке «Данные» кнопку **«Пересчитать»** (занимает несколько секунд).

Дополнительные программы не нужны — только то, что уже есть в проекте.

## Что модуль берёт из проекта преподавателя

| Что | Для чего |
|---|---|
| дорожный граф (узлы и дороги) | считает пешие пути от квартиры до магазинов, школ и остановок |
| остановки, переходы, светофоры | учитываются как места рядом |
| здания | каждая квартира привязывается к зданию проекта; карта красит здания |

## Что модуль записывает в проект

Для каждого здания с квартирами создаются четыре характеристики (их видно в окне здания на главной карте, и другие модули могут ими пользоваться):

- Индекс среды (0–100)
- Цена, ₽/м²
- Чистая доходность, %
- Индекс выгодности (0–100)

При каждом пересчёте старые значения заменяются новыми.

## Что внутри модуля

Три страницы-вкладки:

- **Рейтинг** — карта и таблица квартир; по клику открывается «Паспорт объекта»: параметры, доходность аренды, перепродажа, из чего сложилась оценка, что рядом, минусы, остановки и переходы, выводы.
- **Настройки** — аренда, налоги, веса, цель (сдавать, продать, оба), срок и рост цен. После изменения нажмите «Сохранить и пересчитать».
- **Данные** — сколько объектов, кнопки «Пересчитать» и «Загрузить встроенные данные», загрузка своих объявлений файлом JSON.

Расчёты те же, что на сайте (см. [03](03-how-it-works.md)): аренда по комнатности с поправками в диапазоне 20–35 тыс. ₽, чистая доходность, перепродажа, индекс среды, итоговая оценка.

## Свои таблицы модуля

Модуль создаёт три таблицы, имена начинаются на `realty_`, поэтому с другими модулями они не пересекаются: `realty_flat` (объявления), `realty_poi` (места), `realty_result` (результат по каждой квартире).

## Как обновить встроенные данные

Файл `realty_module.py` собирается автоматически из `module/realty_module.template.py` и данных сайта:

```
python module/build_module.py
```

Команда берёт свежие `dist/data/listings.json` и `dist/data/poi.json` и пересобирает один файл. Править вручную нужно только шаблон, а не готовый `realty_module.py`.

## Ограничения

- Дороги в проекте преподавателя — для машин, тротуаров и дворовых троп в них нет, поэтому пешие расстояния получаются приблизительными.
- Индекс среды — упрощённая оценка, а не научный показатель.
- Расчёт ведётся только для зданий, где есть объявления, а не для всех зданий проекта.
- Фото в модуль не входят, только ссылка на объявление.

## Папка «Для преподавателя» (таблицы БД)

Все таблицы данных проекта выгружаются одной командой:

```
python scripts/export_tables.py            # из готовых данных сайта
python scripts/export_tables.py --collect  # сначала обновить объявления и контуры домов
```

Получается папка `Для преподавателя/`: `Таблицы/*.csv` (по файлу на таблицу), `realty.db` (SQLite, те же таблицы), `load_tables.py` (загрузка CSV в свою базу), `schema.sql` и `README.txt` с описанием колонок и связей. Пользователи и сессии в выгрузку не входят (в CSV только заголовки).
